# Hello-Agents 课程内容总结

本文档整理自 [Hello-Agents](https://github.com/datawhalechina/Hello-Agents) 开源课程，共 16 章，系统介绍了从 Agent 基础概念到完整项目实战的全流程知识体系。

---

## 章节概览

### 第一章 初识智能体
- Agent 的定义：能通过传感器感知环境、通过执行器自主采取行动的实体
- 传统 Agent 的演化：简单反射型 → 基于模型 → 基于目标 → 基于效用 → 学习型
- LLM 驱动的新范式：从规则驱动转向语言理解与推理驱动
- Agent 的组成：任务环境、感知、决策、行动
- 实践：5 分钟实现第一个 Agent

### 第二章 智能体发展史
- 符号主义与逻辑推理的早期 Agent（专家系统、SHRDLU）
- 基于规则的聊天机器人（ELIZA）
- Marvin Minsky 的"心智社会"理论与多 Agent 思想起源
- 强化学习范式的兴起与现代 Agent 的演化路径

### 第三章 大语言模型基础
- 语言模型发展：N-gram → RNN → Transformer
- Transformer 架构解析：Encoder、Decoder、Decoder-Only
- 与 LLM 交互的方式：Prompt Engineering、上下文学习、指令微调
- Token、Embedding、注意力机制的基本原理

### 第四章 智能体经典范式构建
- 环境搭建与工具定义
- **ReAct**（Reasoning + Acting）：推理与行动交替的经典范式
- **ReWOO**：将规划与执行分离，减少冗余调用
- **Self-Ask**：通过自我提问拆解复杂问题
- 各范式的适用场景对比

### 第五章 基于低代码平台的智能体搭建
- 主流低代码平台概览（Dify、Coze 等）
- 无需编写代码，通过可视化界面构建 Agent 工作流
- 适合快速验证想法或非技术背景用户

### 第六章 框架开发实践
- 主流 Agent 框架对比：LangChain、LlamaIndex、AutoGen 等
- 框架核心模块：工具管理、记忆管理、链式调用
- 基于框架快速开发 Agent 应用的完整流程

### 第七章 构建你的 Agent 框架
- 从零设计并实现一个轻量级 Agent 框架（HelloAgents）
- 核心抽象：Agent 基类、工具注册机制、消息传递协议
- 理解框架底层逻辑，脱离黑箱依赖

### 第八章 记忆与检索
- Agent 的记忆类型：短期记忆（上下文窗口）、长期记忆（外部存储）
- 向量数据库的原理与使用（FAISS、Chroma）
- RAG（检索增强生成）：将外部知识注入 Agent
- 记忆管理策略：遗忘、压缩、索引

### 第九章 上下文工程
- 上下文窗口的限制与管理策略
- Prompt 结构设计：系统提示、历史消息、工具描述的组织方式
- 动态上下文：根据任务动态裁剪和填充上下文
- Token 成本优化

### 第十章 智能体通信协议
- 多 Agent 系统中的通信模式：广播、点对点、发布-订阅
- **MCP**（Model Context Protocol）：工具与模型之间的标准化通信协议
- **A2A**（Agent-to-Agent）：Agent 之间的通信规范
- 协议设计对系统可扩展性的影响

### 第十一章 Agentic RL
- 强化学习与 Agent 的结合：从规则驱动到奖励驱动
- RLHF（基于人类反馈的强化学习）在 LLM Agent 中的应用
- Agentic RL 的训练范式：环境定义、奖励设计、策略优化
- 典型案例分析

### 第十二章 智能体性能评估
- 为什么评估 Agent 比评估普通模型更复杂
- 评估维度：任务完成率、工具调用准确率、多轮对话一致性
- 主流评估框架与基准数据集
- 自动化评估 vs 人工评估的取舍

### 第十三章 智能旅行助手（实战）
- 综合运用：规划、工具调用、记忆、多轮对话
- 功能：行程规划、景点推荐、实时查询（天气、交通）
- 项目架构设计与关键代码实现

### 第十四章 自动化深度研究 Agent（实战）
- 类 Deep Research 系统的实现原理
- 多轮搜索 + 信息聚合 + 报告生成的完整流程
- 工具链：网络搜索、文档解析、摘要生成
- 自主规划与迭代细化

### 第十五章 构建赛博小镇（实战）
- 多 Agent 协作的沙盒世界模拟
- NPC Agent 系统：角色设定、记忆系统、对话生成
- 情感系统设计：Agent 间的关系建模
- 后端服务架构与批量对话生成策略

### 第十六章 毕业设计
- 独立构建一个多 Agent 应用的完整指导
- 选题原则与推荐方向
- 开发环境搭建、项目结构规范
- 提交与评审标准

## 与 FrameLearn 的关联

FrameLearn 作为一个视频转图文教程的 Agent 项目，直接对应本课程中的多个核心概念：

| Hello-Agents 知识点 | FrameLearn 中的体现 |
|---|---|
| ReAct 范式（第 4 章） | Planner Agent 的规划-执行循环 |
| 工具调用（第 4、6 章） | yt-dlp、ffmpeg、OCR 工具的注册与调用 |
| 记忆与检索（第 8 章） | QA 模块检索视频内容回答问题 |
| 上下文工程（第 9 章） | 管理长视频分析时的上下文窗口 |
| Agent 评估（第 12 章） | 教程生成质量的自我批评机制 |
| 深度研究 Agent（第 14 章） | 多轮分析与迭代优化的设计参考 |
